# Code Generation Implementation Plan

## Overview

Transform MIR (Mid-level Intermediate Representation) into WLA-DX assembly for the 65816 processor. This is the final phase of the R65 compiler pipeline.

**Input:** MIRProgram with CFG, virtual registers, and mode information
**Output:** WLA-DX assembly (.asm) files ready for assembly

---

## Design Principles (From Existing Docs)

1. **Readable Output**: Clear labels, comments, structured sections
2. **Deterministic**: Same source → same assembly every time
3. **Debuggable**: Source locations at function headers
4. **Explicit Control**: Programmer specifies register usage
5. **Predictable**: Match hand-written assembly patterns
6. **WLA-DX Native**: Follow assembler conventions

---

## Architecture

```
MIRProgram
    ↓
Register Allocator (Virtual → Scratch/Stack)
    ↓
Instruction Selector (MIR → 65816 Instructions)
    ↓
Addressing Mode Selector (Optimize addressing modes)
    ↓
Assembly Emitter (WLA-DX Syntax)
    ↓
Assembly File (.asm)
```

### Phase 3: Register Allocation (Virtual → Physical) 🎯

**Goal:** Map virtual registers to scratch registers or stack

**Strategy** (from register-allocation.md):
1. **Priority**:
   - Hardware registers (A, X, Y) - already allocated by MIR
   - Explicit memory locations (#[zeropage], #[ram])
   - Scratch registers (#[zeropage(addr, register)])
   - Stack (last resort)

2. **Scratch Register Pool**:
   ```python
   class ScratchRegisterAllocator:
       def __init__(self, scratch_pool):
           self.pool = scratch_pool  # List of available scratch locations
           self.allocated = {}       # VirtualRegister → address
           self.free_list = list(scratch_pool)

       def allocate(self, vreg: VirtualRegister) -> int:
           """Allocate scratch location for virtual register"""
           if vreg in self.allocated:
               return self.allocated[vreg]

           if not self.free_list:
               raise Exception("Out of scratch registers!")

           addr = self.free_list.pop(0)
           self.allocated[vreg] = addr
           return addr

       def free(self, vreg: VirtualRegister):
           """Free scratch location (for reuse)"""
           if vreg in self.allocated:
               addr = self.allocated[vreg]
               self.free_list.append(addr)
               del self.allocated[vreg]
   ```

3. **Live Range Analysis** (optional for v1):
   - Track where virtual registers are used
   - Reuse scratch locations when possible
   - For v1: simple linear allocation (one scratch per vreg)

**Test:** Allocate virtual registers from test MIR functions

### Phase 4: Instruction Selection (MIR → 65816) 📝

**Goal:** Convert MIR instructions to 65816 assembly mnemonics

**Instruction Mapping:**

1. **Memory Operations**:
   ```python
   def select_load(self, instr: Load):
       # Load dest = *source
       dest_loc = self.get_location(instr.dest)
       src_loc = self.get_location(instr.source)

       if instr.type_info.is_u8():
           self.emit("LDA", f"${src_loc:04X}")
           self.emit("STA", f"${dest_loc:04X}")
       else:  # u16
           self.emit("LDA", f"${src_loc:04X}")
           self.emit("STA", f"${dest_loc:04X}")
           self.emit("LDA", f"${src_loc+1:04X}")
           self.emit("STA", f"${dest_loc+1:04X}")
   ```

2. **Arithmetic Operations**:
   ```python
   def select_binary_op(self, instr: BinaryOp):
       if instr.op == '+':
           # Load left
           self.load_to_a(instr.left)
           # Add right
           self.emit("CLC")
           if isinstance(instr.right, Immediate):
               self.emit("ADC", f"#{instr.right.value}")
           else:
               self.emit("ADC", self.get_location(instr.right))
           # Store result
           self.store_from_a(instr.dest)
   ```

3. **Control Flow**:
   ```python
   def select_jump(self, instr: Jump):
       self.emit("JMP", f"__L{instr.target}")

   def select_cond_branch(self, instr: CondBranch):
       # Compare condition to 0
       self.load_to_a(instr.condition)
       if instr.comparison == '!=':
           self.emit("BEQ", f"__L{instr.false_target}")
           self.emit("JMP", f"__L{instr.true_target}")
       # ... other comparisons
   ```

4. **Function Calls**:
   ```python
   def select_call(self, instr: Call):
       # TODO: Handle arguments based on mechanism
       if instr.is_far:
           self.emit("JSL", instr.function)
       else:
           self.emit("JSR", instr.function)
       # TODO: Handle returns
   ```

5. **Mode Control**:
   ```python
   def select_set_mode(self, instr: SetMode):
       if instr.is_set:
           self.emit("SEP", f"#${instr.mask:02X}")
       else:
           self.emit("REP", f"#${instr.mask:02X}")
   ```

6. **Stack Operations**:

   ```python
   def select_push(self, instr: Push):
       reg_name = instr.register.name
       if reg_name == 'STATUS':
           self.emit("PHP")
       elif reg_name == 'A':
           self.emit("PHA")
       # ... etc

       reg_name = instr.register.name
       if reg_name == 'STATUS':
           self.emit("PLP")
       # ... etc
   ```

### Phase 5: Addressing Mode Selection 🎲

**Goal:** Choose optimal 65816 addressing modes

**Addressing Modes:**

1. **Immediate**: `LDA #$42`
2. **Direct Page (Zero-Page)**: `LDA $20`
3. **Absolute**: `LDA $7E2000`
4. **Indexed**: `LDA $20,X` or `LDA $2000,X`
5. **Indirect**: `LDA ($42)` or `LDA ($42),Y`

**Selection Logic:**
```python
class AddressingModeSelector:
    def select_mode(self, operand, instruction):
        if isinstance(operand, Immediate):
            return f"#{operand.value}"

        if isinstance(operand, HardwareRegister):
            return operand.name  # A, X, Y

        if isinstance(operand, MemoryLocation):
            addr = operand.address

            # Zero-page (direct page)
            if 0 <= addr <= 0xFF:
                return f"${addr:02X}"

            # Absolute
            else:
                return f"${addr:06X}"

        if isinstance(operand, VirtualRegister):
            # Get allocated location
            addr = self.reg_alloc.get_location(operand)
            return f"${addr:02X}"
```

**Optimizations:**
- Use direct page mode for zero-page addresses (faster, smaller)
- Use indexed modes when appropriate
- STZ optimization (store zero) for 65816

**Test:** Verify optimal addressing modes selected

### Phase 6: Function Code Generation 🔧

**Goal:** Generate complete function bodies with headers

**Function Template:**
```asm
; ============================================================================
; function_name
; Source: file.r65:start-end
;
; Description (if available)
;
; Parameters:
;   <list parameters>
;
; Returns:
;   <list returns>
;
; Preserves: <preserved registers>
; Mode: <processor mode>
; ============================================================================
function_name:
    <instructions>
    RTS
```

**Implementation:**
```python
class FunctionCodeGenerator:
    def generate_function(self, mir_func: MIRFunction):
        # Emit function header
        self.emit_function_header(mir_func)

        # Emit function label
        self.emit_label(f"{mir_func.name}:")

        # Process each basic block in order
        for block_id in self.block_order(mir_func):
            block = mir_func.blocks[block_id]

            # Emit block label (if not entry block)
            if block_id != mir_func.entry_block_id:
                self.emit_label(f"__L{block_id}:")

            # Emit instructions
            for instr in block.instructions:
                self.select_instruction(instr)

        # Ensure function ends with return
        # (already in MIR blocks)
```

**Goal:** Generate complete assembly file with all sections

**Sections:**

   ```asm
   ; Source: main.r65
   ```

   ```asm
       DEFAULTSLOT 0
       SLOTSIZE $8000
       SLOT 0 $8000
   .ENDME

   .ROMBANKMAP
       BANKSTOTAL 1
       BANKSIZE $8000
       BANKS 1
   .ENDRO
   ```

3. **Symbol Definitions**:
   ```asm
   ; Direct Page Allocations
   .DEFINE VAR1 $20

   ; Hardware Registers
   .DEFINE INIDISP $2100

   ; Constants
   .EQU SCREEN_WIDTH 256
   ```

4. **Code Sections**:
   ```asm
   .BANK 0 SLOT 0
   .ORG 0

   ; Functions here
   ```

5. **Interrupt Vectors**:
   ```asm
   .ORGA $FFE4
   .dw 0           ; COP
   .dw 0           ; BRK
   .dw 0           ; ABORT
   .dw nmi_handler ; NMI
   .dw 0           ; (unused)
   .dw 0           ; IRQ
   ```

6. **Symbol Exports**:
   ```asm
   .EXPORT main
   .EXPORT function1
   ```

**Complete Generator:**
```python
class ProgramCodeGenerator:
    def generate(self, mir_program: MIRProgram) -> str:
        emitter = AssemblyEmitter()

        # Header
        emitter.emit_header(source_file)

        # Memory map
        emitter.emit_memory_map()

        # Allocate and define symbols
        memory_alloc = MemoryAllocator()
        memory_alloc.allocate_all(mir_program.statics)
        emitter.emit_symbol_definitions(memory_alloc)

        # Code section
        emitter.emit_bank_directive(0)

        # Generate all functions
        for mir_func in mir_program.functions:
            func_gen = FunctionCodeGenerator(emitter, memory_alloc)
            func_gen.generate_function(mir_func)

        # Interrupt vectors
        emitter.emit_interrupt_vectors(mir_program)

        # Symbol exports
        emitter.emit_exports(mir_program)

        return emitter.to_string()
```

## Key Design Decisions

### 1. Register Allocation Strategy

**Decision:** Use explicit scratch register pool, no complex allocation

**Rationale:**
- Predictable output
- Matches assembly programmer mental model
- Simpler implementation
- Easier debugging

**Implementation:** Linear scan with simple scratch pool

---

### 2. Addressing Mode Selection

**Decision:** Deterministic selection based on address range

**Rationale:**
- Same input → same output
- Simple rules: zero-page vs absolute
- No heuristics or optimization

**Implementation:** Check address range, select mode

---

### 3. Function Calling Convention

**Decision:** Follow MIR argument mechanisms exactly

**Rationale:**
- MIR already encodes calling convention
- Just translate to assembly
- No additional analysis needed

**Implementation:** Map ArgumentMechanism to assembly patterns

---

### 4. Label Generation

**Decision:** Use simple numeric labels for blocks

**Rationale:**
- Clear, unambiguous
- No name conflicts
- Easy to generate

**Implementation:** `__L{block_id}` for blocks, function names for functions

---

### 5. Optimization Level

**Decision:** Start with no optimization (v1), add peephole later (v2)

**Rationale:**
- Correctness first
- Peephole is easy to add later
- Matches design principle (explicit > clever)

**Implementation:** Direct translation MIR → assembly

## Potential Challenges

### 1. Complex Calling Conventions

**Challenge:** Multiple parameter mechanisms (stack, register, variable)

**Solution:** MIR already encodes this - translate directly

---

### 2. 16-bit Values in 8-bit Mode

**Challenge:** Multi-instruction sequences for 16-bit operations in 8-bit mode

**Solution:** Template-based code generation (low byte, high byte)

---

### 3. Stack Management

**Challenge:** Tracking stack pointer for stack parameters

**Solution:** Start with register/variable parameters only (v1)

---

### 4. Bank Management

**Challenge:** Cross-bank calls and data access

**Solution:** Start with single bank (v1), add multi-bank later (v2)
