# Code Generation and WLA-DX Assembly Output

## Overview

R65 compiles to WLA-DX assembly format for the 65816 processor. The code generator produces assembly that is **readable, debuggable, and matches hand-written patterns** while maintaining the explicit control and predictability required for reverse engineering.

**Design Principles**:
- Readable output: Clear labels, comments, and structure
- Deterministic: Same source → same assembly
- Debuggable: Source locations at function headers
- WLA-DX compatible: Follow WLA-DX syntax and conventions
- Bank-aware: Proper bank organization for SNES ROM

---

## WLA-DX Assembly Syntax

### Basic Structure

```asm
.65816                          ; Processor directive
.MEMORYMAP                      ; Memory map definition
    DEFAULTSLOT 0
    SLOTSIZE $8000
    SLOT 0 $8000
.ENDME

.ROMBANKMAP                     ; ROM bank mapping
    BANKSTOTAL 2
    BANKSIZE $8000
    BANKS 2
.ENDRO

.BANK 0 SLOT 0                  ; Bank 0 code
.ORG 0

; Code here

.BANK 1 SLOT 0                  ; Bank 1 code
.ORG 0

; More code here
```

## Symbol Naming Conventions

### Function Names

```rust
// R65
fn process_player() { }

#[bank(1)]
far fn sound_update() { }
```

**Generated**:
```asm
; ============================================================================
; process_player
; Source: player.r65:42-67
; ============================================================================
process_player:
    ; Code
    RTS

.BANK 1
; ============================================================================
; sound_update
; Source: sound.r65:15-89
; ============================================================================
sound_update:
    ; Code
    RTL
```

**Convention**: Use original identifier names, lowercase with underscores

---

### Variable Names

```rust
#[zeropage(0x20)]
static mut TEMP: u8;

#[ram]
static mut BUFFER: [u8; 256];
```

**Generated**:
```asm
.DEFINE TEMP $20

; In data section
BUFFER:
    .DSB 256, 0                 ; Reserve 256 bytes, initialized to 0
```

---

### Compiler-Generated Labels

**Convention**: Prefix with `__` to avoid conflicts

```asm
__init_start:                   ; Initialization routine
    ; Code
    RTS

__mul_u8:                       ; Built-in multiply routine
    ; Code
    RTS

__L1:                           ; Local label (loop/branch target)
    ; Code
    BEQ __L2

__L2:
    ; Code
```

## Function Headers with Source Locations

### Standard Function

```asm
; ============================================================================
; process_player
; Source: player.r65:42-67
;
; Processes player movement and collision
;
; Parameters:
;   A = player_id (u8)
;   X = delta_x (i8)
;
; Returns:
;   A = new_x_position (u8)
;
; Preserves: Y, D, DBR
; Modifies: A, X, STATUS
; Mode: m8, x8
; ============================================================================
process_player:
    LDA player_id
    STA temp
    ; ... assembly instructions ...
    RTS
```

**Key Information**:
- Function name
- **Source file and line range** (main.r65:42-67)
- Function description (if available from doc comments)
- Parameters with types
- Return values
- Register preservation
- Processor mode

## Code Generation Patterns

### Arithmetic Operators

```rust
let result @ A = a + b;
```

**Generated**:
```asm
    LDA a
    CLC
    ADC b
```

**With immediates**:
```asm
    LDA #10
    CLC
    ADC #20
```

---

### Bitwise Operators

```rust
let result @ A = value & 0x0F;
let result @ A = value | 0x80;
let result @ A = value ^ 0xFF;
```

**Generated**:
```asm
    LDA value
    AND #$0F

    LDA value
    ORA #$80

    LDA value
    EOR #$FF
```

---

### Shift Operators (Constant)

```rust
let result @ A = value << 2;    // Multiply by 4
let result @ A = value >> 1;    // Divide by 2
```

**Generated**:
```asm
    LDA value
    ASL A
    ASL A

    LDA value
    LSR A
```

---

### Expensive Operations (Function Calls)

```rust
let result @ A = mul(x, y);
```

**Generated**:
```asm
    LDA x
    LDX y
    JSR __mul_u8
    ; Result in A
```

**Built-in routine at end of file**:
```asm
; ============================================================================
; __mul_u8
; Compiler built-in: 8-bit multiplication
;
; Parameters:
;   A = multiplicand (u8)
;   X = multiplier (u8)
;
; Returns:
;   A = result (u8)
;
; Preserves: Y
; ============================================================================
__mul_u8:
    STX __mul_temp
    LDX #0
    ; Multiplication loop
    RTS
```

---

### Control Flow

#### If Statement

```rust
if x > 10 {
    do_something();
}
```

**Generated**:
```asm
    LDA x
    CMP #10
    BCC __L1                    ; Branch if x <= 10 (unsigned)
    BEQ __L1

    JSR do_something

__L1:
    ; Continue
```

---

#### If-Else

```rust
if x == 0 {
    zero_case();
} else {
    non_zero();
}
```

**Generated**:
```asm
    LDA x
    BNE __L1                    ; Not zero, go to else

    JSR zero_case
    JMP __L2                    ; Skip else

__L1:
    JSR non_zero

__L2:
    ; Continue
```

---

#### Loop

```rust
loop {
    process();
    if done {
        break;
    }
}
```

**Generated**:
```asm
__L1:                           ; Loop start
    JSR process

    LDA done
    BNE __L2                    ; Break if done != 0

    JMP __L1                    ; Continue loop

__L2:                           ; After loop
    ; Continue
```

---

#### While Loop

```rust
while counter > 0 {
    work();
    counter = counter - 1;
}
```

**Generated**:
```asm
__L1:                           ; Loop condition check
    LDA counter
    BEQ __L2                    ; Exit if counter == 0

    JSR work

    LDA counter
    DEC A
    STA counter

    JMP __L1

__L2:
    ; Continue
```

---

```

---

#### Far Call (JSL/RTL)

```

**Generated**:

; Source: main.r65:30-33
; ============================================================================

### Pointer Operations

#### Near Pointer Dereference

```rust
#[zeropage(0x42)]
static mut PTR: near<u8>;

fn read() -> u8 {
    let value @ A = *PTR;
    return value;
}
```

**Generated**:
```asm
.DEFINE PTR $42

; ============================================================================
; read
; Source: main.r65:45-48
; ============================================================================
read:
    LDA (PTR)
    RTS
```

---

#### Indexed Access

```rust
let value @ A = PTR[Y];
```

**Generated**:
```asm
    LDA (PTR),Y                 ; Indirect indexed
```

---

### Mode Transitions

#### Manual Mode Change

```rust
REP(0x20);                      // m16 mode
A = 1000;
SEP(0x20);                      // Back to m8
```

**Generated**:
```asm
    REP #$20                    ; 16-bit accumulator
    LDA #1000
    SEP #$20                    ; 8-bit accumulator
```

---

#### Automatic Mode Transition (transition=auto)

```rust
#[mode(m16, x16, transition=auto)]
fn safe_function(value @ A: u16) -> u16 {
    return value + 1;
}
```

**Generated**:
```asm
; ============================================================================
; safe_function
; Source: utils.r65:50-53
;
; Parameters:
;   A = value (u16)
;
; Returns:
;   A = result (u16)
;
; Mode: m16, x16 (auto-transition)
; ============================================================================
safe_function:
    PHP                         ; Save processor status
    REP #$30                    ; m16, x16 mode
    CLC
    ADC #1
    PLP                         ; Restore processor status
    RTS
```

## Bank Organization

### LoROM Memory Map

```asm
; ============================================================================
; Memory Map (LoROM)
; ============================================================================
.MEMORYMAP
    DEFAULTSLOT 0
    SLOTSIZE $8000              ; 32KB banks
    SLOT 0 $8000                ; Mapped at $8000
.ENDME

.ROMBANKMAP
    BANKSTOTAL 4                ; 4 banks = 128KB ROM
    BANKSIZE $8000              ; 32KB each
    BANKS 4
.ENDRO
```

**Bank Layout**:
```
Bank $00: $8000-$FFFF (32KB)  - Main code
Bank $01: $8000-$FFFF (32KB)  - Additional code
Bank $02: $8000-$FFFF (32KB)  - Graphics/Sound
Bank $03: $8000-$FFFF (32KB)  - Data tables
```

---

### HiROM Memory Map

```asm
; ============================================================================
; Memory Map (HiROM)
; ============================================================================
.MEMORYMAP
    DEFAULTSLOT 0
    SLOTSIZE $10000             ; 64KB banks
    SLOT 0 $0000                ; Mapped at $0000
.ENDME

.ROMBANKMAP
    BANKSTOTAL 4                ; 4 banks = 256KB ROM
    BANKSIZE $10000             ; 64KB each
    BANKS 4
.ENDRO
```

## Data Sections

### Direct Page (Zero-Page) Section

```rust
#[zeropage(0x20)]
static mut TEMP: u8;

#[zeropage(0x22)]
static mut COUNTER: u16;

#[zeropage]  // Compiler allocates
static mut AUTO_ALLOC: u8;
```

**Generated**:
```asm
; ============================================================================
; Direct Page Allocations
; ============================================================================
.DEFINE TEMP $20                ; Explicit - main.r65:5
.DEFINE COUNTER $22             ; Explicit - main.r65:8
.DEFINE AUTO_ALLOC $24          ; Auto-allocated - main.r65:10
```

**Allocation Strategy**:
- Explicit addresses: Use as specified
- Auto-allocated: Compiler assigns from first free location
- Track usage to avoid conflicts
- Reserve $00-$0F for system use

---

### RAM Section

```rust
#[ram]
static mut BUFFER: [u8; 256];

#[ram(0x7E2000)]
static mut PLAYER_DATA: [u8; 100];
```

**Generated**:
```asm
; ============================================================================
; RAM Allocations
; ============================================================================

; Auto-allocated
BUFFER:
    .DSB 256, 0                 ; 256 bytes, zero-initialized

; Explicit address
.DEFINE PLAYER_DATA $7E2000
```

---

### ROM Section (Read-Only Data)

```rust
#[rom]
static GRAPHICS: [u8; 4096] = include_bytes!("gfx.bin");

#[rom]
static SIN_TABLE: [u8; 256] = [
    0x80, 0x83, 0x86, // ... more values
];
```

**Generated**:
```asm
.BANK 0 SLOT 0

GRAPHICS:
    .INCBIN "gfx.bin"           ; 4096 bytes from external file

SIN_TABLE:
    .DB $80, $83, $86, $89, $8C, $8F, $92, $95
    .DB $98, $9B, $9E, $A2, $A5, $A8, $AB, $AE
    ; ... (optimized for readability - 8 values per line)
```

---

## Debugging Support

### WLA-DX Symbol Generation

**Compiler flags to pass to WLA-DX**:
```bash
wla-65816 -i output.asm         # Include list data in .obj
wlalink -S -A linkfile rom.sfc  # Generate symbols with addr-to-line mapping
```

This generates a `.sym` file with `[addr-to-line mapping v2]` section mapping ROM addresses to assembly source lines.

---

### Source Location Tracking

**Only at function boundaries** (not every line):

```asm
; ============================================================================
; process_frame
; Source: main.r65:85-120
; ============================================================================
process_frame:
    JSR update_player
    JSR update_enemies
    JSR check_collisions
    RTS

; ============================================================================
; update_player
; Source: player.r65:15-45
; ============================================================================
update_player:
    LDA player_x
    ; ... more code
    RTS
```

**Benefits**:
- Clean, readable assembly
- Source traceability at function level
- Shows line range for each function
- Not cluttered with per-instruction comments

---

### Symbol Exports

```asm
; Export public symbols for debugging
.EXPORT main
.EXPORT process_player
.EXPORT vblank
.EXPORT TEMP
.EXPORT BUFFER
```

## Complete Example

**Source (main.r65)**:
```rust
#[zeropage(0x20)]
static mut FRAME_COUNT: u16 = 0;

#[hw(0x4212)]
static mut HVBJOY: u8;

#[interrupt(nmi)]
fn vblank() {
    FRAME_COUNT = FRAME_COUNT + 1;
}

fn wait_vblank() {
    loop {
        let status @ A = HVBJOY;
        if (status & 0x80) != 0 {
            break;
        }
    }
}

#[entry]
#[mode(m8, x8)]
fn main() -> ! {
    loop {
        wait_vblank();
        // Process frame
    }
}
```

## Assembly Comment Style

### Section Headers

```asm
; ============================================================================
; Section Name
; ============================================================================
```

**Used for**:
- Major sections (Bank 0, Allocations, Vectors)
- Function headers
- Data tables

---

### Inline Comments

```asm
    LDA #$0F
    STA $2100               ; INIDISP = 0x0F (screen brightness)

    CMP #60                 ; Check if counter >= 60
    BCC __L1                ; Branch if less
```

**Guidelines**:
- Add inline comments for hardware register writes
- Explain non-obvious comparisons or branches
- Don't comment obvious operations (LDA, STA to named variables)

## Optimization Considerations

### Peephole Optimization (Optional)

**Pattern 1: Redundant Load**
```asm
; Before
LDA #10
STA temp
LDA temp                        ; Redundant - A already has value

; After
LDA #10
STA temp
```

**Pattern 2: Branch Simplification**
```asm
; Before
BEQ __L1
JMP __L2
__L1:

; After
BNE __L2
; Fall through
__L1:
```

**Pattern 3: Constant Folding**
```asm
; Before (from: let x = 10 + 20 + 30)
LDA #10
CLC
ADC #20
CLC
ADC #30

; After
LDA #60
```

---

### Dead Code Elimination

```asm
; Before
JMP target
LDA #10                         ; Dead - never executed

; After
JMP target
```

## Build Process

### Compilation Steps

1. **Parse** R65 source → AST
2. **Type check** → Validated HIR
3. **Code generation** → WLA-DX assembly (.asm)
4. **Assemble** with WLA-DX:
   ```bash
   wla-65816 -i output.asm -o output.obj
   ```
5. **Link** with wlalink:
   ```bash
   wlalink -S -A linkfile output.sfc
   ```
6. **Output**:
   - `output.sfc` - SNES ROM file
   - `output.sym` - Symbol file with debugging info

---

### Link File Format

```
[objects]
output.obj

[output]
output.sfc

[symbols]
output.sym
```

## Summary

### Code Generation Principles

1. **Readable**: Clear formatting, section headers, meaningful names
2. **Debuggable**: Source locations at function headers, symbol exports
3. **Deterministic**: Same source → same assembly output
4. **Efficient**: Peephole optimization, constant folding
5. **WLA-DX Native**: Follow assembler conventions and best practices

### Key Features

- Function headers with source file and line range
- Section organization (allocations, code, vectors)
- Symbol preservation for debugging
- Automatic initialization routine generation
- Interrupt vector table setup
- Clean assembly output matching hand-written style
- Support for both LoROM and HiROM layouts

### Debug Information Flow

```
R65 Source (main.r65)
    ↓
Generated Assembly (output.asm) [with source locations in headers]
    ↓
WLA-DX Assembly (wla-65816 -i)
    ↓
Object File (output.obj) [with list data]
    ↓
WLA Linker (wlalink -S -A)
    ↓
Symbol File (output.sym) [addr-to-line mapping for .asm]
```

**Result**: Debuggers can map ROM addresses → assembly lines. Function headers provide assembly lines → R65 source lines.
